## 简介

SurviWar 是一个适用于 Minecraft Java 版的多人团队生存 PVP 数据包。玩家以队伍为单位进入主世界收集资源、武装自己，随后被传送至竞技场展开最终对战。

你可以将它理解为一场节奏更紧凑的大型“战墙”：前期生存发育，后期正面对抗，存活到最后的队伍获胜。

> 本数据包需要配合专用资源包使用：[下载 SurviWar 配套资源包](https://github.com/Mxpea/surviwar-resourcepack)

## 玩法

1. 玩家在大厅中选择参与或旁观，并选择队伍；也可以选择随机分队。
2. 至少需要 2 名参与玩家和 2 支已启用队伍。所有参与玩家准备后，游戏自动开始倒计时。
3. 开局后，各队玩家会被分散传送到主世界的不同位置。
4. 玩家拥有 10 分钟收集资源、制作装备并为战斗做好准备。
5. 收集阶段结束后，所有参赛玩家会被传送到竞技场并开启 PVP。
6. 玩家进行 3 分钟的最终对战，存活到最后的队伍获得胜利。

死亡的玩家会进入旁观模式。若对战时间结束时仍未决出胜者，本局以平局结束。

## 安装

1. 下载本仓库，并将其中的 `surviwar` 文件夹放入存档的 `datapacks` 目录。
2. 下载并安装 [SurviWar 配套资源包](https://github.com/Mxpea/surviwar-resourcepack)。
3. 进入存档，或在游戏内执行 `/reload` 重新加载数据包。
4. 所有玩家进入大厅、选择队伍并准备后即可开始游戏。

## 功能

- 独立的游戏大厅与竞技场维度
- 16 支可配置颜色队伍
- 手动选队与随机均衡分队
- 参与、旁观与准备状态管理
- 自动开局、阶段计时与竞技场传送
- 游戏内 GUI、教程和 Boss 栏提示
- 中英文文本支持
